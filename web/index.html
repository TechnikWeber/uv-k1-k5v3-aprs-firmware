APRS Messenger for UV-K1 / UV-K5 V3

F4HWN Fusion v7 with its overlay apps, plus APRS messaging built into the firmware: mailbox, channels, lobby (CQ and APRS-IS groups), position beacon, station list, multi-tap typing, optional encryption where it is allowed.

Beta. Tested live: messages and acks on the air, with dual watch. This build on F4HWN v7 with the overlay apps has run on the radio for three days of daily use without a problem. Please report what you find in the issues. Transmitting APRS needs an amateur radio licence. Encryption is forbidden on amateur bands; elsewhere follow your country's rules.

Flash it from the browser

  1. Back up the calibration first (once per radio): flash the official Fusion firmware, then dump the calibration in UV Studio and keep the file, named after the radio's serial number.
  2. Connect the radio with a data USB cable and put it into DFU mode; UV Studio shows how.
  3. Open UV Studio with this firmware already loaded, then select Flash Firmware and the radio's serial port.
  4. Keep the cable connected after the flash: UV Studio restarts the radio and writes the firmware assets (fonts, menu texts and the messenger's texts) in two more steps. Until then the radio's screen stays blank; that is expected.
  5. The restarted radio is a new USB device for the browser: the firmware's own serial port (USB name PUYA CDC DEMO), not the bootloader's. The first time in a browser, UV Studio asks for it under the steps: click Select the radio and pick that port. The browser remembers it, so later flashes run through by themselves. Done when UV Studio says Firmware assets written and verified.

If the asset step fails, the radio is fine: it runs the new firmware and only lacks its texts. With the radio on normally (not in DFU mode), click Install firmware assets in the same UV Studio tab. That button only shows after a failed step: in a new tab, flash the file once more.

Chrome, Edge, Opera or Firefox 151+ on a computer (Web Serial). On Linux your user needs the dialout group (uucp on Arch): without it the port is listed, but Connect does nothing. Add it with sudo usermod -aG dialout $USER, then log out and in again. Flashing goes through the radio's bootloader, which is never overwritten; the calibration stays in its own flash sector. Back to stock: restore the calibration file, or use UV Studio's factory reset for the UV-K1 / UV-K5 V3.

After flashing

  1. Menu → a side key setting (F1Shrt … M Long) → MESSAGES.
  2. Press it: enter your callsign, switch the messenger ON.
  3. Tune VFO B to 144.800 MHz (IARU Region 1): FM, wide, no offset, no tones, compander off. With voice on VFO A: RxMode MAIN TX / DUAL RX.

Examples, settings, the APRS channel on VFO B and voice with APRS in two pages: the quick start. How messages travel (direct, digipeater, Internet): how it works. Everything else: the user guide.

Overlay apps

New with v7: the F4HWN apps (KISS TNC, APRS RX/TX/DIGI, SSTV, sondes, CW tools, games, …) run on this firmware as on the official Fusion. For the messenger you give up almost nothing: only the spectrum analyser (the Spectrum3D app shows the band), the RF Log, the QR codes and the logo screen saver are left out to make room.

  1. Install them with UV Studio: the radio switched on as usual and connected by USB, then Apps.
  2. Start them on the radio: F, then 7 opens the app menu; MENU starts the selected app, EXIT closes the menu.
  3. While an app runs, the messenger pauses: no reception, no sending. It goes on by itself when you leave the app, and a message sent to you meanwhile comes with the sender's next retry.

CHIRP

The F4HWN CHIRP driver does not know the side-key actions MESSAGES and APRS ON/OFF: it shows them as NONE and resets them when it writes the settings. This build comes with its own driver, the F4HWN v7.0.0 driver plus these actions. Load it in CHIRP with File → Load Module (newer CHIRP versions show it after Help → Developer Mode).
